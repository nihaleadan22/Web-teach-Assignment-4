# Web-tech-Assignment-4
Markdown Slides

Open index.html in a browser. Files: index.html (structure), style.css (look), script.js (logic).

Requirements checklist
 HTML, CSS and JavaScript only
 Create, edit, save (localStorage) and present slides
 One markdown text; --- separates slides
 Edit screen has 2 sections: markdown editor + realtime slide view
 Left, Right, Full Screen buttons (Left disabled on first slide, Right on last)
 Full screen button text changes to "Exit Full Screen" in presentation mode
 Keyboard: Left/Right arrows, F11, Ctrl+S
 Slide counter at the bottom: current / total
 Slides reload from browser memory after closing the browser
 Extras: download/open .md, unsaved-changes warning, code blocks
